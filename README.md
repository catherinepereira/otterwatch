# Otterwatch

Live otter webcam status board with automatic otter detection.

- [`frontend/`](frontend/README.md) — React + TypeScript + Vite app on Vercel, subscribes to Supabase Realtime.
- [`backend/`](backend/README.md) — detstream deployment: detects otters on the feeds and pushes sightings to Supabase + Discord.

See each folder's README for setup
